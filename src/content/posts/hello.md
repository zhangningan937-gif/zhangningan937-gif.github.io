我之前做过一个「通信原理学习台」，四十多篇笔记、一百多条公式、一百多道题，都放在里面。它的好处是快：考前搜一个词，定义、图和例题立刻出来。

但它有个毛病——里面的东西全是「答案的形状」。公式是对的，推导是顺的，可当初为什么卡住、怎么想通的、哪一步其实绕了远路，全都看不见。学习台像一个整理好的工具箱，不像一个人在学习。

所以又搭了这个博客。这里不追求齐全，只记录三件事：

- **学习**：一门课、一个概念，我到底是怎么理解的，哪里想错过。
- **折腾**：装环境、改代码、把东西跑起来的过程，包括踩的坑。
- **随笔**：偶尔写点跟课程无关的。

技术上没什么新鲜的：Astro 加 Fuwari 主题，构建成纯静态页面，托管在 GitHub Pages。没有数据库，没有后台，写完 Markdown 推到仓库就完事。这样做的好处是十年后大概还能打开，坏处是我得自己记得备份。

如果你是从学习台过来的，那边继续更新题目和速查；这边更新慢一点，但会更像人话。

订阅可以走 [RSS](/rss.xml)，虽然我不确定自己更新得够不够勤。
